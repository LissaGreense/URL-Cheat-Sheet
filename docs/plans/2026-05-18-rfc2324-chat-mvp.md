# RFC 2324 Chat MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> `superpowers:subagent-driven-development` (recommended) or
> `superpowers:executing-plans` to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking. Each task in this
> plan becomes its own `bd` issue via the `task-creation` skill
> (pipeline stage 4); implementing teammates work one issue at a time
> on `feat/<bd-id>-<slug>` branches.

**Goal:** Ship the first working slice of URL-Cheat-Sheet — a chat UI that
answers questions about a statically bundled copy of RFC 2324 (HTCPCP),
grounded by a single substring-grep tool the backend agent calls.

**Architecture:** SvelteKit page (`+page.svelte`) hosts a `@ai-sdk/svelte`
`Chat` client. It POSTs `{ messages }` to `/api/chat`, which validates the
body with Zod and calls `streamChat()` in `@url-cheat-sheet/agent`. The
agent calls `streamText` (Anthropic Sonnet 4.6) with one tool —
`grep_rfc` — which runs a case-insensitive literal substring search over
a bundled RFC 2324 text file.

**Tech stack:**
- SvelteKit 2 + Svelte 5 (runes), Vite 8 (Rolldown)
- Vercel AI SDK v6 (`ai` core) + `@ai-sdk/anthropic` v3 provider
- `@ai-sdk/svelte` v4 for the client `Chat`
- Zod 4 (`z.strictObject`)
- Vitest, jsdom (web), node (agent)
- Bun runtime / lockfile

**Spec:** [`../specs/2026-05-18-rfc2324-chat-mvp.md`](../specs/2026-05-18-rfc2324-chat-mvp.md)

```ts
    expect(matches[0].line).toBe(2);

    expect(hit.after).toEqual(['fifth line', 'sixth line plain']);

    expect(hit.line).toBe(1);
    expect(hit.before).toEqual([]);
    expect(hit.after).toEqual(['second line has coffee', 'third line plain']);

    expect(hit.line).toBe(7);
    expect(hit.before).toEqual(['fifth line', 'sixth line plain']);
    expect(hit.after).toEqual([]);

  it('returns an empty array when nothing matches', () => {
    expect(grepLines(sample, 'no-such-token')).toEqual([]);
  });

  it('caps results at 20 matches', () => {

    const matches = grepLines(dense, 'coffee');
    expect(matches).toHaveLength(20);
    expect(matches[0].line).toBe(1);
```

- [ ] **Step 3: Implement the tool**

Create `packages/agent/src/tools/grep-rfc.ts`:

```ts
import { tool } from 'ai';
import { z } from 'zod';
import rfcText from '../data/rfc2324.txt?raw';

const MAX_MATCHES = 20;
const CONTEXT_LINES = 2;

export interface GrepMatch {
  line: number;
  text: string;
  before: string[];
  after: string[];
}

/**
 * Case-insensitive literal substring search over a line-broken text.
 * Returns up to MAX_MATCHES hits, each with up to CONTEXT_LINES lines
 * of surrounding context. Line numbers are 1-based.
 */
export function grepLines(text: string, pattern: string): GrepMatch[] {
  const lines = text.split('\n');
  const needle = pattern.toLowerCase();
  const matches: GrepMatch[] = [];

  for (let i = 0; i < lines.length; i++) {
    if (!lines[i].toLowerCase().includes(needle)) continue;
    matches.push({
      line: i + 1,
      text: lines[i],
      before: lines.slice(Math.max(0, i - CONTEXT_LINES), i),
      after: lines.slice(i + 1, Math.min(lines.length, i + 1 + CONTEXT_LINES)),
    });
    if (matches.length >= MAX_MATCHES) break;
  }

  return matches;
}

export const grepRfc = tool({
  description:
    'Search RFC 2324 (HTCPCP) for a case-insensitive substring. Returns matching lines with up to two lines of surrounding context. Pattern is treated as literal text, not regex.',
  inputSchema: z.strictObject({
    pattern: z.string().describe('Case-insensitive substring to search RFC 2324.'),
  }),
  execute: async ({ pattern }) => ({
    matches: grepLines(rfcText, pattern),
  }),
});
```

```ts
import { anthropic } from '@ai-sdk/anthropic';
import { convertToModelMessages, stepCountIs, streamText, type UIMessage } from 'ai';
import { SYSTEM_PROMPT } from './prompt.ts';
import { grepRfc } from './tools/grep-rfc.ts';

/**
 * Stream a chat response grounded in RFC 2324. The model may call the
 * grep_rfc tool zero or more times before producing its answer.
 *
 * The Anthropic API key is read from process.env.ANTHROPIC_API_KEY by
 * the provider; missing keys surface as a runtime error from the
 * provider call, which the route handler converts to a 500.
 */
export function streamChat(messages: UIMessage[]) {
  return streamText({
    model: anthropic('claude-sonnet-4-6'),
    system: SYSTEM_PROMPT,
    messages: convertToModelMessages(messages),
    tools: { grep_rfc: grepRfc },
    stopWhen: stepCountIs(5),
  });
}
```

Create `apps/web/src/routes/api/chat/+server.ts`:

```ts
import { json, type RequestHandler } from '@sveltejs/kit';
import type { UIMessage } from 'ai';
import { streamChat } from '@url-cheat-sheet/agent';
import { chatRequestSchema } from '@url-cheat-sheet/schemas';

/**
 * Chat endpoint. Validates the @ai-sdk/svelte Chat client body, then
 * streams the model response (with the grep_rfc tool wired in) back
 * to the browser via the AI SDK's UI message stream.
 */
export const POST: RequestHandler = async ({ request }) => {
  let raw: unknown;
  try {
    raw = await request.json();
  } catch {
    return json({ error: 'Body must be valid JSON' }, { status: 400 });
  }

  const parsed = chatRequestSchema.safeParse(raw);
  if (!parsed.success) {
    return json(
      { error: 'Invalid request body', issues: parsed.error.issues },
      { status: 400 },
    );
  }

  if (!process.env.ANTHROPIC_API_KEY) {
    return json({ error: 'ANTHROPIC_API_KEY not set' }, { status: 500 });
  }

  // The Zod schema validates structure (id, role, parts: unknown[]). The AI
  // SDK validates each part shape inside convertToModelMessages, so a single
  // boundary cast here is the cleanest place to bridge the two type worlds.
  const result = streamChat(parsed.data.messages as UIMessage[]);
  return result.toUIMessageStreamResponse();
};
```
